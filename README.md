# SearchItemPath

### How to run the console application

* Please update SearchForItem/TestDataFile/TestFile.txt with paths and items. A sample TestFile is added in case you want to update it please follow the structure on the sample context. The aplication checks the file structure too. So if it doesn't find + or Item: it will throw an error.(Do NOT change the file name)
* Run RunApp.bat from the project folder. (This bat file will build the slnx and will start running exe from bin/debug folder)
